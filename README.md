## System Overview

- **Company:** KlimaShift (Avrio Energy)
- **System:** 3 Energy Meters × 5 channels = 15 channels (C1–C15)
- **C1, C2, C3:** Reserved for 3-Phase Incoming Mains
- **C4–C15:** Available for MCB mapping

## Site Audit Flow Summary

| Part | Steps | Description |
|------|-------|-------------|
| A | 1–8 | Client & Building Selection |
| B | 9–12 | Building Details & Orientation |

| D | 17–20 | 3D Room Scan (iPhone Required) |
| E | 21–34 | Asset Audit |
| F | 35–45 | Electrical Panel Audit |

| H | 55–56 | End Audit |
| I | 57–61 | Post-Audit: Meter Installation Planning |

## Requirements

- KlimaShift Operations App
- iPhone (12 or newer with LiDAR) for 3D scanning
- Multimeter for MCB phase testing
- Safety PPE (gloves, shoes, goggles, hard hat, insulated mat)
